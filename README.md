# 🧮 Calculadora em C

Projeto desenvolvido em linguagem C com o objetivo de praticar lógica de programação, operações matemáticas e entrada de dados.

## 🚀 Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Validação de entradas inválidas
- Tratamento de divisão por zero

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Biblioteca padrão `stdio.h`
- Compilador GCC

## ▶️ Como executar

Compile o programa usando o GCC:

```bash
gcc main.c -o calculadora
```

Execute no terminal:

**Windows:**

```bash
calculadora.exe
```

**Linux:**

```bash
./calculadora
```

## 📚 Objetivo acadêmico

Praticar variáveis, entrada e saída de dados, estruturas condicionais, operadores aritméticos e compilação de programas em C.
